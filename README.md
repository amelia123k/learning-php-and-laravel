# Mini Inventory

A simple PHP inventory project created to practice PHP fundamentals.

## Features

- Add products
- Enter product price and quantity
- Validate product information
- Calculate total price
- Check if a product already exists
- Prevent duplicate products
- Search for products
- Save new product information to a file
- Read saved inventory information
- Use PHP sessions

## Technologies

- PHP
- HTML
- File handling
- PHP Sessions

## PHP Concepts Practiced

- Variables
- Arrays
- Conditions
- `if`, `else`, and `elseif`
- `foreach`
- Functions and array functions
- Forms
- `$_POST`
- `isset()`
- `empty()`
- `in_array()`
- `array_push()`
- File handling
- Sessions

## How to Run

1. Make sure PHP is installed.
2. Open the project folder in a terminal.
3. Start the PHP development server:

//bash
php -S localhost:8080
